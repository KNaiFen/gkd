# Documentation governance

GKD 的长期知识按职责分层，避免同一事实被多处改写：

- `VISION` 保存长期使命、用户承诺、成功标准、原则、冲突顺序、非目标与演进规则。它不保存当前实现状态或决定索引。
- `decision` 记录材料性产品、授权或跨实现承诺的上下文、选择和影响。新决定取代旧决定时保留历史并明确关系。
- `ADR` 记录重要架构选择、替代方案和技术后果。架构改变时新增记录，不覆盖旧理由。
- `AGENTS` 保存当前目录内 Agent 必须遵守的硬规则、执行边界和最近事实源入口，不复制愿景正文。
- `Skill/reference` 保存可复用工作流与领域参考，负责教会 Agent 如何执行，不获得新的项目授权。
- `repo policy` 保存仓库特有门禁、资源和 CI 选择；通用 GKD 机制只读取并服从，不把它升级成全局 policy。

`.agents` 是当前运行记忆，用于交接正在发生的状态。它不是完整 decision/ADR 历史，本基础任务也不把既有运行记忆伪装成历史迁移。

方案在材料性规划前填写短 `Vision Alignment`。该分析只解释一致性与张力，不改变授权；只有方案确实依赖某项长期决定时才引用该方案自己的 decision/ADR。
