# GKD

GKD 工作流的规范源码、版本管理与专属验证仓库。

长期使命、用户承诺和冲突取舍以唯一的 [VISION](VISION.md) 为准。

当前仓库提供可扩展的 development bundle foundation、确定性任务核心、固定角色/路由核心，以及 project-scoped automatic runtime bridge。M2-A custom-role 握手与 M2-B 一小时等待门保持绑定历史执行 bundle；M2-C 候选通过非生产项目 staging、六门 route decision、main-role-only exact spawn activation/claim 和分离的执行/输出 bundle 摘要，使显式自动路线达到 `automatic_runtime_bridge_ready`。默认路线仍为 manual，candidate-facing task claim 与公开 role automatic CLI 均 fail-closed；生产安装、AIO 接入和 M3 功能不在本结果内。

Canonical CLI、project staging 与 automatic runtime bridge 要求 Python 3.11 或更高版本。
