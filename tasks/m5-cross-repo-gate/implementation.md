# GKD-M5-C Implementation

## Internal Design

Keep source release identity separate from sandbox repository identity. The L4 observation must bind canonical marker bytes at the observed sandbox head, while final promotion remains anchored to the GKD source SHA. Eval-only L3 is a read-only record contract.

## Execution Details

Implement the approved scope in the registered worktree, use the versioned verifier and write delivery. Do not execute live L3/L4, tag, release, accept or merge.
